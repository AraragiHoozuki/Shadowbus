# 本地双选规则

`TwoPick` 目录下的每个 `.json` 文件都定义一个可在 P2P 建房界面选择的双选模式。
房主建房时读取并规范化所选规则，访客加入后会收到房主的完整规则，不需要本地
存在同名文件。双方各自在本地随机生成候选牌，只有完成后的牌组会用于 P2P 对战匹配。

## 基础字段

- `id`：模式的稳定内部标识，不区分大小写；多个文件不能使用相同的 `id`。省略时
  使用文件名（不含 `.json`）作为 `id`。
- `displayName`：建房规则选项、房间标题中显示的模式名称。
- `finalDeckSize`：最终牌组张数，必须是 6 至 200 之间的偶数。至少需要 6 张，
  才能支持起手时替换全部 3 张牌。
- `candidateClassCount`：使用原版界面时必须保持为 `3`。
- `offersPerRound`：使用原版界面时必须保持为 `2`。
- `cardsPerOffer`：使用原版界面时必须保持为 `2`。
- `allowDuplicatePicks`：是否允许已经进入牌组的卡再次出现在后续轮次。
- `sameCardLimit`：同一卡牌 ID 在最终牌组中的可选数量上限；`null` 表示不设置。
- `candidateClasses`：可能出现在三个候选职业位置中的职业 ID。
- `classRules`：按候选职业 ID 配置混合职业卡池和介绍文本。
- `roundRules`：按抓牌轮次配置费用、稀有度或特定卡牌限制。
- `cardPool`：全局基础卡池。`null` 表示从所有普通非 Token 卡生成；数组表示只以
  数组中的卡牌为基础，再根据 `classRules` 过滤。
- `excludedCards`：全局硬排除的卡牌 ID，优先级高于其他卡池配置。
- `cardWeights`：卡牌 ID 到正整数权重的映射，用于改变符合条件的卡牌出现概率。

原版界面目前固定为三个候选职业、每轮左右两组、每组两张牌。改变这些布局参数
需要制作新的双选界面。

## 多职业混合卡池

职业 ID `0` 表示中立，`1` 至 `8` 表示八个普通职业。某个候选职业没有对应的
`classRules` 时，默认使用该职业和中立卡，保持原版行为。

- `cardClasses`：允许进入该候选职业卡池的职业。它会替换默认的“本职业＋中立”。
  设置为空数组表示不自动加入任何职业的卡。
- `displayName`：多职业候选面板显示的自定义名称。省略或设为 `null` 时显示候选
  主战者原本的职业名称。
- `additionalCards`：额外加入该候选职业卡池的卡牌 ID。即使卡牌职业未列入
  `cardClasses`，或卡牌不在全局 `cardPool` 中，也会加入。
- `description`：点击该候选职业后显示的介绍文本；省略或设为 `null` 时使用原版文本。

职业选择页会汇总该候选在所有抓牌轮次中实际可能出现的非中立职业。包含多个职业时，
候选面板会复用原版混沌双选布局显示全部职业图标；`additionalCards` 和 `roundRules.cards`
引入的额外职业也会计入。中立卡不会额外显示职业图标。

```json
"classRules": {
  "1": {
    "displayName": "精灵皇家混合",
    "cardClasses": [0, 1, 2],
    "additionalCards": [123456789],
    "description": "使用精灵、皇家与中立卡牌的混合卡池。"
  },
  "3": {
    "displayName": "巫师龙族混合",
    "cardClasses": [3, 4],
    "additionalCards": [],
    "description": "使用巫师与龙族卡牌的混合卡池。"
  }
}
```

## 抓牌轮次限制

轮次从 `1` 开始。默认 30 张牌、每轮选择 2 张时，一共有 15 轮。同一轮只能由
一条 `roundRules` 规则定义；没有匹配规则的轮次使用普通职业卡池。

- `rounds`：应用该规则的轮次列表。
- `costs`：允许出现的原始费用列表。`null` 或空数组表示不限制费用。
- `rarities`：允许出现的稀有度列表。`1` 为铜、`2` 为银、`3` 为金、`4` 为虹；
  `null` 或空数组表示不限制稀有度。
- `cards`：该轮的特定卡牌 ID。非空时，它会成为该轮的完整卡池，并忽略
  `costs`、`rarities`、`cardClasses`、`additionalCards` 和全局 `cardPool`。
  全局 `excludedCards` 仍然生效。

每轮需要生成四张互不相同的候选牌，因此过滤后的卡池至少要包含四张可用卡。
如果同名卡上限导致后续轮次无法生成四张候选牌，本次选牌会明确报错，而不会
自动放宽规则。

```json
"roundRules": [
  {
    "rounds": [1, 8, 15],
    "costs": null,
    "rarities": [3, 4],
    "cards": null
  },
  {
    "rounds": [4, 10],
    "costs": [1, 2, 3],
    "rarities": [1, 2],
    "cards": null
  },
  {
    "rounds": [7],
    "costs": [99],
    "rarities": [4],
    "cards": [111111111, 222222222, 333333333, 444444444]
  }
]
```

上例中第 1、8、15 轮只出现当前混合职业卡池中的金卡和虹卡；第 4、10 轮只出现
1 至 3 费的铜卡和银卡；第 7 轮只从 `cards` 指定的四张牌中生成候选，费用 `99`
和虹卡限制会被忽略。
